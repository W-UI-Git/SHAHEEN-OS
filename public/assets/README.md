This package contains the initial production-ready visual identity assets for SOOQMARKET.AI.

- logo/ — vector symbol and wordmarks
- icons/ — web/PWA icons in common sizes + favicon
- app/ — mobile/PWA application icons
- social/ — social/open-graph artwork
- brand/ — brand guidelines and color tokens
